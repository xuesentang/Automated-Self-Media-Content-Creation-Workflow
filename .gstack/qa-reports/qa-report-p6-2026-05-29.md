## Issues Found

### ISSUE-001 | High | Functional
**Mentor 审阅 SSE 返回无效 JSON**

- Repro: 提交初稿 → LLM 生成反馈 JSON 时偶发拼写错误（如 `problemTyp` 缺 `e`）
- Impact: 用户需要点"重试"重跑，增加等待时间
- Root cause: DeepSeek API 偶尔生成不完整或有拼写错误的 JSON；`max_tokens` 未设导致长响应被截断
- Fix applied: `backend/services/llm.py:7` — `stream_llm` 添加 `max_tokens=8192`
- Status: **verified** (mitigated, 不可完全消除——LLM 天生非确定性)
- Files: `backend/services/llm.py`

### ISSUE-002 | Medium | UX
**localStorage 持久化状态恢复后白屏**

- Repro: 工作流状态转换后，从导航栏点击 `/workflow` 时页面空白
- Impact: 需要清除 localStorage 或加 cache-busting URL 参数恢复
- Root cause: `usePersistedMachine` 恢复状态时，并行状态机的 value 结构与 XState 预期不完全一致，React 渲染崩溃（静默，无 error boundary 捕获）
- Fix: 未修（需要 XState v5 state rehydration 调试，建议 P6 后单独处理）
- Status: **deferred** (workaround: localStorage.clear() + reload)
- Files: `frontend/src/hooks/usePersistedMachine.ts`

### ISSUE-003 | Low | Operational
**端口累积占用导致开发者混淆**

- Repro: 多次重启 Vite 后端口 5173-5180 全部被死进程占用
- Impact: 开发者导航到旧端口看到空白页，误判为应用 bug
- Fix: 未修（运维问题，建议添加启动脚本自动清理死进程）
- Status: **deferred**
